# EFATA mobile theme

The mobile color scheme is generated by `EfataTheme`. The temporary brand accent
is blue. To preview a new EFATA accent, pass an opaque ARGB color at build time:

```powershell
flutter build apk --dart-define=EFATA_ACCENT_ARGB=0xFF2356A8
```

The build flag changes the light and dark color schemes together. Error, warning,
and status colors are separate; don't use the accent to replace them. The
`customer` wire role is retained for compatibility. Passenger is the user-facing
label.

Driver home displays the total recorded amount for completed deliveries, not
a withdrawable balance. The detailed breakdown is on the driver profile.
On the map, drivers see the SDK's My Location indicator and passengers see the
SDK's standard marker at the latest available driver position. The consumer
Google Maps 3D car isn't exposed by the Maps SDK as a marker asset.
